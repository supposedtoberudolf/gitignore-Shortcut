# Gitignore Command

A personal Git Bash command that quickly creates a `.gitignore` file for programming projects.

## Purpose

This repository contains my custom `gitignore` command, which I can use in different programming projects to automatically create a `.gitignore` file with commonly ignored files.

The goal is to make setting up new Git repositories faster and avoid accidentally committing unnecessary generated or temporary files.

## Usage

After setting up the command in Git Bash, simply run:

```bash
gitignore
